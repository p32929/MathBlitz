# MathBlitz

A small maths practice game for the terminal, written in C. Pick a level and it keeps giving you random sums: addition, subtraction, multiplication, division and modulo. When you get one wrong, it shows you the right answer, so you learn as you go.

Five levels, which only change how big the numbers get:

| Level | Number range |
|---|---|
| 1 | 1–10 |
| 2 | 1–20 |
| 3 | 1–50 |
| 4 | 1–100 |
| 5 | 1–200 |

## Prerequisites

Any C compiler, like `gcc`, `clang` or MinGW. There is also a `.cpp` copy if you prefer a C++ compiler.

## Build and run

```bash
gcc "MathBlitz 1.0.c" -o mathblitz
./mathblitz
```

Pick a level number, then answer questions until you close the program. To switch levels, restart it.
