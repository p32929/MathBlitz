# MathBlitz

A small terminal maths drill written in C. Pick a difficulty level, and it keeps throwing randomly generated arithmetic at you — addition, subtraction, multiplication, division, modulo — telling you the right answer when you miss.

Five levels, which only change how big the numbers get:

| Level | Number range |
|---|---|
| 1 | 1–10 |
| 2 | 1–20 |
| 3 | 1–50 |
| 4 | 1–100 |
| 5 | 1–200 |

## Prerequisites

A C compiler (`gcc`, `clang`, MinGW — anything). There's also a `.cpp` copy if you'd rather use a C++ compiler.

## Build and run

```bash
gcc "MathBlitz 1.0.c" -o mathblitz
./mathblitz
```

Pick a level number, then answer questions until you close the program. To switch levels, restart it.
